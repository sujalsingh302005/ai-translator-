# 🌍 AI Translator App

A powerful **AI-based Translator Application** built using Python that supports **Text, Voice, and Camera input** to break language barriers and enable seamless global communication.

---

## 📌 Project Overview

The AI Translator App allows users to translate content in real-time using different input methods:

Instead of using separate tools, this app combines everything in one place:

- 🔤 Text input → Instant translation  
- 🎤 Voice input → Speech to text  
- 📸 Camera input → OCR-based text detection  
- 🔊 Output → Spoken translation (multi-language)

This project demonstrates practical implementation of **AI + NLP + Computer Vision**.

---

## ⚡ Features

- 🔤 **Text Translation** → Translate text into multiple languages  
- 🎤 **Voice Input** → Speak and convert speech to text  
- 🔊 **Text-to-Speech Output** → Listen to translated text (supports Hindi 🔥)  
- 📸 **Camera Translation** → Capture and translate text using OCR  
- 🌐 **Multi-language Support** → Hindi, English, French, Spanish, German, Japanese, Chinese  
- 📋 **Auto Copy** → Automatically copies translated text  
- 🎨 **Clean GUI** → Built using Tkinter  

---

## 🧠 Tech Stack

- 🐍 Python  
- 🖥️ Tkinter (GUI)  
- 🌐 Deep Translator (Translation API)  
- 🎤 SpeechRecognition (Voice Input)  
- 🔊 gTTS (Voice Output)  
- 📸 OpenCV (Camera)  
- 🔍 Pytesseract OCR (Text Detection)

## ▶️ How to Run

### 1. Clone the repository
git clone https://github.com/sujalsingh302005/ai-translator-app.git  
cd ai-translator-app  

### 2. Install dependencies
pip install -r requirements.txt  

### 3. Install Tesseract (Mac)
brew install tesseract  

### 4. Run the application
python3 main.py
