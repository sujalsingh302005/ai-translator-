# 🌍 AI Translator App (Text + Voice + Camera)

## 🚀 Overview
The AI Translator App is a Python-based desktop application that enables real-time translation using multiple input methods including text, voice, and camera.

This project aims to break language barriers and enable seamless global communication using Artificial Intelligence technologies such as Natural Language Processing (NLP), Speech Recognition, and Optical Character Recognition (OCR).

---

## ✨ Features

- 🔤 **Text Translation** – Translate text instantly into multiple languages  
- 🎤 **Voice Input** – Speak and convert speech into text  
- 🔊 **Text-to-Speech Output** – Listen to translated text (supports Hindi & more)  
- 📸 **Camera Translation** – Capture and translate text using OCR  
- 🌐 **Multi-language Support** – Hindi, English, French, Spanish, German, Japanese, Chinese  
- 📋 **Auto Copy** – Automatically copies translated text to clipboard  
- 🎨 **Modern GUI** – Clean and interactive interface using Tkinter  

---

## 🧠 Tech Stack

- **Python**
- **Tkinter** – GUI Development  
- **Deep Translator** – Translation API  
- **SpeechRecognition** – Voice Input  
- **gTTS (Google Text-to-Speech)** – Voice Output  
- **OpenCV** – Camera Integration  
- **Pytesseract OCR** – Image Text Detection  

---

## ⚙️ Installation

### 1. Clone the Repository
```bash
git clone https://github.com/sujalsingh302005/ai-translator-app.git
cd ai-translator-app
````

### 2. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 3. Install Tesseract (Mac)

```bash
brew install tesseract
```

---

## ▶️ How to Run

```bash
python3 main.py
```

---

## 🎯 How It Works

1. User provides input (Text / Voice / Camera)
2. Voice is converted to text using SpeechRecognition
3. Image text is extracted using OCR (Pytesseract)
4. Text is translated using Deep Translator
5. Output is displayed and spoken using gTTS
