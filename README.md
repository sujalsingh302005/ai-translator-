# 🌍 AI Translator App (Text + Voice + Camera)

## 🚀 Overview
The AI Translator App is a Python-based application that enables real-time translation using multiple input methods such as text, voice, and camera.

This project focuses on breaking language barriers and enabling seamless communication using AI-powered tools like NLP, Speech Recognition, and OCR.

---

## ✨ Features

- 🔤 **Text Translation** – Translate text instantly into multiple languages  
- 🎤 **Voice Input** – Convert speech to text using microphone  
- 🔊 **Text-to-Speech Output** – Listen to translated text in different languages  
- 📸 **Camera Translation** – Capture and translate text using OCR  
- 🌐 **Multi-language Support** – Hindi, English, French, Spanish, German, Japanese, Chinese  
- 📋 **Auto Copy** – Translated text is automatically copied to clipboard  
- 🎨 **User-Friendly GUI** – Built using Tkinter  

---

## 🧠 Tech Stack

- **Python**
- **Tkinter** – GUI  
- **Deep Translator** – Language translation  
- **SpeechRecognition** – Voice input  
- **gTTS (Google Text-to-Speech)** – Speech output  
- **OpenCV** – Camera handling  
- **Pytesseract OCR** – Text extraction from images
